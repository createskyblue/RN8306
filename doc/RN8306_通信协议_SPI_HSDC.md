# RN8306（RN830x / RN730x V3 系列）通信协议整理

> 依据官方资料整理，供 MCU 驱动开发使用。
> 芯片厂商：深圳市锐能微科技有限公司（Renergy，隶属上海贝岭/华大半导体体系）。
> 适用芯片：RN8302B / RN8302C / **RN8306** / RN7302 / RN7306（V3 版）。
>
> **名称澄清**：本文所说的接口是 **HSDC**（High-Speed Data Channel，波形缓存高速输出接口）。
> 注意与"华大半导体"缩写 HDSC 无关，也不是芯片厂商名——它是 RN8306/RN7306 特有的一组引脚
> （HSCSN / HSCLK / HSDAO）构成的串行波形输出端口。RN8302B/RN7302 上对应引脚为 NC（无此接口）。

---

## 0. 接口总览

RN8306 与 MCU 之间共有 **两条独立的串行链路**（见数据手册典型应用图 4.3/4.4）：

| 链路 | 引脚 | 角色 | 用途 |
|---|---|---|---|
| **SPI**（串行通信接口） | SCSN(34)、SCLK(33)、SDI(35)、SDO(32) | 芯片为 **SPI 从机**，MCU 为主机 | 读/写寄存器（配置、校表、读计量数据、Burst 读波形缓存） |
| **HSDC**（高速波形输出） | HSCSN(1)、HSCLK(42)、HSDAO(44) | 芯片为 **SPI 主机**，MCU 配置为从机只收 | 波形缓存（ADC 原始采样）自动推送到 MCU |
| 辅助 | INT1(31)、INT2(30)、RSTN(26) | 芯片输出 | 中断（含 HSDC 半块输出/错误中断）、复位 |

HSDC 与普通 SPI 相互独立：HSDC 由波形缓存模块联动自动发送，不需要 MCU 发起读命令。

## 1. SPI 从机接口（寄存器访问）

### 1.1 基本参数（用户手册 V1.2 第 5 章，p140）

- 工作方式：**从机（Slave）**；速率最高 **3.5 Mbps**；3.3V/5V 兼容。
- **SCSN**：片选，低有效，输入，内部悬空，**必须外接上拉电阻**。
  - SCSN 由高变低：移位寄存器复位，进入通讯状态；
  - SCSN 由低变高：通讯结束，通讯口复位到空闲。
- **SCLK**：时钟输入，所有传输与 SCLK 同步。
- **SDI / SDO**：数据输入/输出；SCSN 为高时 SDO 呈高阻态。
- 边沿规则（原文）："芯片在 SCLK **上升沿**将数据从 SDO 引脚输出；主机在 SCLK 上升沿将数据从 SDI 引脚输出。芯片和主机都在 SCLK **下降沿**读取数据。"
  - 即数据在上升沿翻转、下降沿采样，对应 MCU 侧 **SPI 模式 1（CPOL=0, CPHA=1）**。
- 传输可靠性：每帧含校验和字节；写保护；写校验寄存器；通信线可加 RC 滤波（串联 1k/2kΩ + 对地 ~100pF，按需取值）。

### 1.2 地址空间（11 位地址 AD[10:0]，Bank 映射）

| 完整地址 | Bank（CMD 中 AD[10:8]） | 空间 |
|---|---|---|
| 0x000–0x0FF | 3'b000 | 计量参数寄存器（EMM 校表寄存器等） |
| 0x100–0x1FF | 3'b001 | 配置和状态寄存器（SYSCFG、SOFTRST、HDSC_CTL 等） |
| 0x200–0x27F | 3'b010 | 波形采样数据缓存块 1 |
| 0x280–0x2FF | 3'b010 | 波形采样数据缓存块 2 |
| 0x300–0x37F | 3'b011 | 波形采样数据缓存块 3 |
| 0x380–0x3FF | 3'b011 | 波形采样数据缓存块 4 |
| 0x400–0x47F | 3'b100 | 波形采样数据缓存块 5 |
| 0x480–0x4FF | 3'b100 | 波形采样数据缓存块 6 |
| 0x500–0x57F | 3'b101 | 波形采样数据缓存块 7 |
| 0x600–0x611 | 3'b110 | 计量寄存器 2（全波计量参数） |

- `ADDR` 字节放地址低 8 位（AD[7:0]），Bank 号放进 CMD 字节。
- 寄存器字长不固定：**1 / 2 / 3 / 4 字节**，以手册寄存器列表"字长"列为准（部分寄存器可用 WREN2 的扩位命令改字长）。

### 1.3 帧格式（三类帧）

```text
写操作（主机全程驱动）：
  MCU → 芯片： [ADDR] [CMD] [DATA(MSB...LSB)] [CS]

读操作（前两字节主机驱动，其后芯片驱动）：
  MCU → 芯片： [ADDR] [CMD]
  芯片 → MCU：             [DATA(MSB...LSB)] [CS]

BURST 读（寄存器或波形缓存）：
  MCU → 芯片： [ADDR] [CMD]
  芯片 → MCU：             [DATA0][DATA1]...[DATAbl-1] [CS]
```

**CMD 字节位定义**（bit7 → bit0；BL 位序按正文序，厂商代码证实）：

| bit7 | bit6:4 | bit3:2 | bit1 | bit0 |
|---|---|---|---|---|
| R/W | AD[10:8]（Bank 号） | BL[1:0] | BL[2] | 0 |

- **R/W = 0 表示读，R/W = 1 表示写**（读帧 CMD 首位 1'b0、写帧 1'b1，两代手册一致）。
- BL[2:0]（仅 Burst 读有效，写操作时 BL 无效**但仍参与校验和计算**）：

| BL[2:0] | Burst 读长度 | 说明 |
|---|---|---|
| 000 | 1 | 单地址（普通读寄存器/读一个波形） |
| 001 | 4 | 连续 4 个地址 |
| 010 | 8 | 连续 8 个地址 |
| 011 | 16 | 连续 16 个地址 |
| 100 | 32 | **仅波形数据读取可用** |
| 101 | 64 | **仅波形数据读取可用** |

> ⚠ **已裁决（2026-10-25）**：手册 5.3 存在自相矛盾——正文（p140）写
> `CMD = {R/W, AD[10:8], BL[1:0], BL[2], 1'b0}`（BL[1:0]@bit[3:2]、BL[2]@bit[1]），
> 帧格式表（p141）写 `{R/W, AD[10:8], BL[2:0], 1'b0}`。**厂商官方 fnRN8302_ReadBuf()
> （Dl645_Fft.c，burst 读 16 地址）写 `CMD |= 0x0C` 证实正文序正确，帧格式表为排版笔误。**
> 据此各 BL 档位的 CMD 低 4 位：000→0x00、001→0x04、010→0x08、011→0x0C、100→0x02、101→0x06。

- Burst 读时地址自动"递增"；寄存器 Burst 读**每个寄存器固定读出 32bit**；波形 Burst 读**每个数据固定 24bit**。
- 数据字节序：多字节先发高字节（MSB）、后发低字节；每字节内高位比特在前。

**示例**（均可直接套用）：

```text
写 Bank1 的 86H（MODSEL）写入 1 字节 0x00：
  ADDR=0x86, CMD=0x90（写|Bank1）, DATA=0x00
  CS = ~(0x86+0x90+0x00) = 0xE9
  帧：86 90 00 E9

读 Bank1 的 8FH（DeviceID，3 字节，复位值 0x830200）：
  MCU 发：8F 10（读|Bank1）
  芯片回：[3 字节数据 MSB→LSB] [1 字节校验和（芯片计算）]

Burst 读波形缓存 Bank2 起 16 个数据（BL=011）：
  CMD = (R/W<<7) | (Bank<<4) | ((BL&3)<<2) | ((BL>>2&1)<<1)   ← 正文序(厂商代码证实)
  Bank=010、BL=011(16) 时 CMD = 0x20 | 0x0C = 0x2C，帧：[偏移地址] [0x2C]，
  随后芯片连续回 16 个 24bit 数据 + 校验和。
```

### 1.4 校验和算法（CS 字节）

> **CS = ~(ADDR + CMD + DATA) 的单字节和取反**
> （原文："ADDR+CMD+DATA 单字节求和取反"）

- 写帧：由 **MCU** 计算并发出；芯片校验。
- 读帧/Burst 帧：由 **芯片** 计算并发出；MCU 校验。
- Burst 读中越界地址读出的 0 **依然参与**芯片侧校验和计算。
- 读帧校验不匹配时软件应丢弃该帧并重读。

### 1.5 时序要点（5.4 / 5.5 节）

1. 以字节为单位传输，高位在前；多字节寄存器先高后低。
2. 主机在 SCLK 高电平输出数据，芯片在 SCLK **下降沿**采样；芯片在 SCLK **上升沿**输出 SDO。
3. 数据字节之间的间隔 **t1 ≥ 0.5 个 SCLK 周期**。
4. 最后一个字节 LSB 传完后，SCSN 拉高结束本帧；SCLK 下降沿到 SCSN 上升沿的 **t2 ≥ 0.5 个 SCLK 周期**。
5. **有写保护的寄存器必须先写写使能命令再写**（见 1.6）。

### 1.6 写保护（3.6 节）与驱动标准流程

- 除写使能寄存器外，**所有可写寄存器及命令寄存器均带写保护**；上电复位/软件复位后默认处于写保护态。
- 写使能寄存器 1（WREN, 0x180, 1B）：写入 **WREN=0xE5** 解除写保护，写入 **WRDIS=0xDC** 恢复写保护（手册 3.4.35, p112；早期整理误记"WRDIS 值未给出"，已订正）。
- 写使能寄存器 2（WREN2, 0x17F, 4B）：寄存器值 **bit[15:8]=命令字（WREN2=0xE5 / WRDIS2=0xDC）**、**bit[7:0]=扩位命令（EXTEN_EN=0xAA / EXTEN_DIS=0x55）**，bit[31:16] 保留。解锁写 `0x0000E5AA`（总线序 `00 00 E5 AA`），上锁写 `0x0000DC55`。
  **注意**：厂商 HSDC.c 中 `{0xAA, 0xE5, 0, 0}` 是 CPU 小端内存序（联合体），不能直接照抄到总线序——原样上总线会让命令字落在保留位（bit[23:16]），WREN2 写使能静默失效（2026-10 驱动审核发现并已在驱动中修复）。
- `SYSSR`（Bank1 8AH）中的 REG_WE 位反映当前写保护状态。
- 扩位：WREN2 收到 EXTEN_EN/EXTEN_DIS 命令可将指定寄存器（Bank1 0CH~12H、37H~39H、8DH）在默认字长与新字长间切换（如 WData 3/4 字节）。

**标准写寄存器流程**：WREN(0xE5) → WREN2(0x0000E5AA) → 写寄存器 →（回读校验）→ WRDIS(0xDC) / WREN2(0x0000DC55) 恢复保护。

### 1.7 可靠性设计（5.6 节）

- **WData**（Bank1 8DH，读，3/4 字节）：保存最近一次 SPI 写入的数据，可回读核对。
- **CHECKSUM1**（0x6A）/ **CHECKSUM2**（Bank1 8BH，读）：EMM 校表寄存器、NVM1/NVM2 及系统配置寄存器的校验和，用于上电自检。
- **DeviceID**（Bank1 8FH，读，3 字节）：复位值 **0x830200**，驱动初始化时可读它确认通信正常。
- **LRBufAddr**（Bank1 8EH）：最后一次读波形缓存的地址。
- 硬件：SCSN 外接上拉；干扰环境可在 SCLK/SDI/SDO 上串 1k/2kΩ 并对地 ~100pF。

### 1.8 SPI Burst 读注意事项（5.7 节）

1. 地址空缺（如 Bank 内空洞）时读出 0。
2. Bank0 越界可继续读到 Bank1（两者地址连续）。
3. Bank1 越界读出 0（Bank1 与波形缓存地址不连续）。
4. 波形缓存 Burst 读越界部分读出 0（校验和仍计入这些 0）。

## 2. HSDC 接口（波形缓存高速输出，芯片为主机）

### 2.1 定位与特性（用户手册 V1.2 第 6 章，p145）

> **HSDC 是一个遵循 SPI 协议的主机接口**，由 HSCSN、HSCLK、HSDAO 3 根线组成，
> **仅支持向从机发送数据，不支持接收数据**。MCU 侧把硬件 SPI 配成从机（只收）即可对接。

- 与波形缓存联动：**缓存存满半块存储空间时，HSDC 自动启动一波发送**。
- 时钟极性（CPOL）/相位（CPHA）可配置；手册时序图默认 **CPOL=0, CPHA=1**。
- HSCLK 速率 4 档：**4.096MHz / 2.048MHz / 1.024MHz / 512kHz**。
- 支持 24bit 波形数据拓展为 32bit 传输（高 8 位补 0）。
- 帧尾校验可选：**8bit 累加、32bit 结果的校验和（未取反）** 或 **CRC16**（多项式 x¹⁶+x¹²+x⁵+1，初值 0）。
- 支持波形数据**按字节反序**或**按位反序**发送。
- 有延时模式下帧间隔可配 8 个 HSCLK。

### 2.2 波形缓存组织（6.2 节）

- 内部专用波形存储：**128 采样点 × 7 通道 × 3 字节 = 2688 Bytes**，半块/满块乒乓（交叉缓存下分上半块/下半块）。
- 7 通道：**UA、UB、UC、IA、IB、IC、IN**（IN 在防窃电方案为零线电流，4V+3I 硬件中作为第 4 路电压输入），每采样点 24bit 原始 ADC 值。
- 缓存格式由 **BUFCFG[4:0] = { DMA_WAVECON3[1], WSAVECON[3:0] }** 选择：
  - **通道分块缓存**（DMA_WAVECON3.BIT10=0）：各通道按块存放（地址映射表见手册 6.2.1）；
  - **通道交叉缓存**（DMA_WAVECON3.BIT10=1）：按采样点顺序各通道数据交叉排列（手册 6.2.2）。
- **常用 BUFCFG 组合（2026-10 复核订正）**：
  - 6 通道 UA/UB/UC/IA/IB/IC 交叉 → **mode0（BUFCFG=5'b00000）**，即厂商 `WSAVECON=0x80 + DMA_WAVECON3=0x400`；每采样点序 UA,UB,UC,IA,IB,IC；
  - **7 通道（4V+3I）交叉 → BUFCFG=5'b10010**，即 `WSAVECON=0x82（低 4 位=0010）+ DMA_WAVECON3[1]=1`；每采样点序 **UA,UB,UC,IA,IB,IC,IN**，半块 200H~3BFH / 3C0H~57FH（备选 BUFCFG=10101/mode17 亦为 7 通道、半块同为 448 地址，但每采样点顺序为 **UA,IA,UB,IB,UC,IC,IN**；早期版本误记 01011 为 7 通道备选——01011=mode11 属手册排版错乱区、读作 IC 单通道，2026-10-25 已订正）；
  - **陷阱**：只置 DMA_WAVECON3[1]=1 而 WSAVECON[3:0]=0000（BUFCFG=10000）**不是 7 通道**，帧定界会错位。该表存在排版笔误，两次审读分别读作 6 通道/纯 IN——无论哪种都不是 7 通道。
  - **3/4 通道档（mode1/2=UA,UB,UC 或 IA,IB,IC 三路、mode13=BUFCFG 10001=UA,UC,IA,IC 四路、mode16）为芯片固定通道集合**，且 3ch 档半块为 128 点/通道（非 64 点），与"任意选 N 路"语义不同；随附驱动仅支持 6/7 通道（wave_channels 收敛），如需 3/4 通道档请先上板验证 BUFCFG 映射再扩展。（mode13 的 BUFCFG 一份外部审核曾误记为 0x0D，正确为 0x11，已按 6.2.2 表头+6.3.2 的 256 地址半块订正。）
- 发送顺序与缓存模式一致（6.3 节）：缓存**上半块**与**下半块**交替发送，例如交叉模式 mode0~12 上半块 200H–37FH、下半块 380H–4FFH（mode14/17 为 200H–3BFH / 3C0H–57FH）。

### 2.3 发送模式与帧结构（6.4 节）

**A. 无延时连续发送（GAP_EN=0）**——常用模式

- 帧长 = **半个缓存空间的全部数据**；帧与帧间隔 **≥ 4 个 T_HSCLK**（期间 HSCSN 拉高）。
- 流程：波形缓存半满/满中断标志拉起 → HSCSN 拉低 → 连续移出半块数据（可选帧尾校验）→ HSCSN 拉高。
- 帧内结构（按 HDSC_CTL 配置组合）：

| 配置（GAP_EN=0） | 帧结构 |
|---|---|
| CHK_EN=0, EXT_EN=0 | `WAVEDATA0[23:0] … WAVEDATAn[23:0]`（纯 24bit 数据流） |
| CHK_EN=0, EXT_EN=1 | `WAVEDATA0[31:0] …`（每点 32bit，高 8bit=0） |
| CHK_EN=1, CHK_SEL=1, EXT_EN=0 | `WAVEDATA0..n[23:0]` + **CRC16[15:0]**（初值 0） |
| CHK_EN=1, CHK_SEL=1, EXT_EN=1 | `WAVEDATA0..n[31:0]` + **CRC16[15:0]** |
| CHK_EN=1, CHK_SEL=0, EXT_EN=0/1 | `WAVEDATA0..n` + **CHKSUM[31:0]**（8bit 累加和，结果 32bit，**不取反**） |

**B. 有延时发送（GAP_EN=1）**

- 每 **8bit**（FWIDTH=0）或 **24/32bit**（FWIDTH=1，随 EXT_EN）为一帧，MSB 先发；
- 帧间隔 **8 个 T_HSCLK**，HSCSN 每帧拉高一次；**该模式不发送校验**。
- 8bit 模式下一个 24bit 采样拆成 [23:16]→[15:8]→[7:0] 三帧依次发出。

### 2.4 字节/位序示例（6.7.1 备注表，发送顺序从左到右）

| BIT_INV | EXT_EN | BYTE_INV | data 发送顺序 | 说明 |
|---|---|---|---|---|
| 0 | 0 | 0 | {data[23:16], data[15:8], data[7:0]} | 原始波形数据 |
| 1 | 0 | 0 | {data[0:7], data[8:15], data[16:23]} | 按位反序 |
| 0 | 0 | 1 | {data[7:0], data[15:8], data[23:16]} | 按字节反序（先发低字节） |
| 1 | 0 | 1 | {data[16:23], data[8:15], data[0:7]} | 按字节反序且按位反序 |
| 0 | 1 | 0 | {8'h0, data[23:16], data[15:8], data[7:0]} | 32bit 拓展 |
| 1 | 1 | 0 | {data[0:7], data[8:15], data[16:23], 8'h0} | 拓展后按位反序 |
| 0 | 1 | 1 | {data[7:0], data[15:8], data[23:16], 8'h0} | 拓展后按字节反序 |
| 1 | 1 | 1 | {8'h0, data[16:23], data[8:15], data[0:7]} | 拓展后按字节反序且按位反序 |

### 2.5 校验结果寄存器 HSDC_CRC（6.7.2）

- 地址 **CAH**（Bank1，即完整地址 0x1CA），4 字节，只读。
- HSDC 对每次输出的波形自动做 CRC16 或累加和计算，结果存于此寄存器，**每发送半块更新一次、初值 0**。
- MCU 可通过普通 SPI 读它，与本地计算结果比对做链路自检（CRC16 结果在低 16 位；累加和为 32bit 全宽）。

### 2.6 HDSC_CTL 寄存器（6.7.1）

- 地址 **C9H**（Bank1，完整地址 **0x1C9**），字长 4 字节，**复位值 0x04**。
- 受 EMU 时钟控制；**各参数仅在 HSDC_EN=0 时可配置**；出错（EMUIF2.HSDC_ERR_IF=1）时 EN 位自动清零。

| 位 | 名称 | 功能 | 复位值 |
|---|---|---|---|
| 31:9 | Reserved | — | 0 |
| 12 | BIT_INV | 波形按 bit 反序发送使能 | 0 |
| 11 | EXT_EN | 0=发原始 24bit；1=发 32bit 拓展（高 8 位补 0） | 0 |
| 10 | BYTE_INV | 波形按 byte 反序发送使能 | 0 |
| 9 | CHK_SEL | 0=8 位累加校验和（结果 32 位，不取反）；1=16 位 CRC | 0 |
| 8 | GAP_EN | 0=无延时；1=帧间延时 8×T_HSCLK | 0 |
| 7 | FWIDTH | 帧长度：0=8bit；1=24bit（仅有延时模式有效） | 0 |
| 6:4 | CLKDIV | f_HSCLK = f_sysclk′ / (2²×(CLKDIV+1))：000=4.096MHz；001=2.048MHz；010=1.024MHz；011=512kHz；其他=4.096MHz（f_sysclk′=8.192MHz） | 0 |
| 3 | CHK_EN | 1=帧尾带校验（仅连续发送模式有效） | 0 |
| 2 | CPHA | HSDC 时钟相位选择 | 1 |
| 1 | CPOL | HSCLK 空闲电平：0=低；1=高 | 0 |
| 0 | EN | HSDC 接口使能 | 0 |

> 注：C9H/CAH 的位定义以第 6.7 节 HSDC 专用章节为准。厂商参考代码使用宏 `RN8306_HDSC_CTRL`。

### 2.7 HSDC 相关寄存器速查（均为 Bank1，完整地址=0x100+偏移）

### 2.8 使用流程（手册 6.5 节）与厂商参考代码（HSDC.c）

**手册标准流程：**

1. 配置 `HDSC_CTL`：传输速度、传输模式等（在 EN=0 时配好）；
2. 按需配置 `EMMIE2[12:11]`：HSDC 错误中断、半块缓存输出中断使能；
3. `HDSC_CTL.EN=1` 使能 HSDC 接口；
4. 配置 `WSAVECON[3:0]`（模式 0）或 `DMA_WAVECON3[0]`（模式 1/2）启动波形缓存；缓存半满后 HSDC 自动发送，发送期间 BUSY=1，半块发完 BUSY=0 暂停；配置了 `EMMIE2.HSDC_TWAVE_HIE=1` 则产生输出中断；
5. 不需要时 `HDSC_CTL.EN=0` 关闭接口。

**厂商参考初始化代码**（`供应商提供的使用HSDC的参考源码HSDC.c`，逐行标注）：

```c
// 1) 开写保护（两级）
//    注意: 厂商缓冲区为 CPU 小端联合体, WREN2 的 {0xAA,EN,0,0} 是内存序,
//    等效寄存器值为 0x0000E5AA(命令字 bit[15:8]=0xE5 + 扩位命令 bit[7:0]=0xAA),
//    真正上 SPI 总线的大端字节序应为 00 00 E5 AA —— 直接照抄厂商字节序会失效!
WREN  = WREN_EN;                    // 写使能寄存器 1
WREN2 = {0xAA, WREN_EN, 0, 0};      // 写使能寄存器 2（0xAA 密钥）

// 2) 系统配置打开 HSDC 功能
SYSCFG = (SYSCFG & …) | 0xEA000000 | 0x1000;   // 读-改-写；bit12 使能 HSDC 引脚功能

// 3) 软复位
SOFTRST = 0xE1;   // 复位 MMU 波形缓存 DMA
SOFTRST = 0x4C;   // 复位 HSDC

// 4) 波形格式与 EMM DMA 模式：UA UB UC IA IB IC，固定 256 点
WSAVECON     = 0x80;
DMA_WAVECON  = 0x04;               // 256 点同步采样(DS_CFG=00; 用驱动实现时须显式
     //                            设置 cfg.sync_sample_hz=点/周波x基频, 否则守卫拒绝)
DMA_WAVECON3 = 0xC00;              // 交叉缓存模式（BIT10=1）

// 5) 配置并打开 HSDC 的 SPI
HDSC_CTL = 0x0000040D;  // 按字节写入 {0x0D,0x04,0,0}：
     // bit0 EN=1 使能；bit2 CPHA=1（默认）；bit3 CHK_EN=1 带校验；
     // bit9 CHK_SEL=0 → 8bit 累加校验和（结果 32bit，不取反）；
     // bit10 BYTE_INV=1 按字节反序（先发低字节）；CLKDIV=000 → HSCLK=4.096MHz；EXT_EN=0 → 24bit/点

// 6) 启动 EMM DMA
DMA_WAVECON3 = 0xC00 | 0x01;       // BIT0=1 启动
DMA_WAVECON2 = 0x00000700;         // 通道使能组合

// 7) 关写保护
WREN  = WREN_DIS;
WREN2 = {0xAA, WREN_DIS, 0, 0};
```

### 2.9 数据量与 HSCLK 速率分析（6.6 节）

**数据量 = n × f × ch × 24（bit/s）**，n=每周期采样点数，f=电网频率，ch=通道数。

| 场景（60Hz，点/周波×60Hz 换算） | 数据量 = 采样率×ch×24 | 所需最小 HSCLK | 占用率 |
|---|---|---|---|
| 256 点 × 4 通道（15.36k） | 1.475M | 2.048M | 72% |
| 256 点 × 3 通道 | 1.106M | 2.048M | 54% |
| 256 点 × 2 通道 | 0.737M | 1.024M | 72% |
| 256 点 × 7 通道 | 2.580M | 4.096M | 63% |
| 512 点 × 7 通道（30.72k） | 5.161M | **不支持**（超 4.096M 上限） | >100% |
| 512 点 × 4 通道 | 2.949M | 4.096M | 72% |
| 512 点 × 6 通道 | 3.687M | 4.096M | 90%（手册 6.6 认可的边界行） |

> 注：本表早期版本多数行误按 80Hz 计算（超出手册 2.4.2 的 40~70Hz 跟踪范围），
> 2026-10-25 已按 60Hz 重算。选型判据以手册 6.6 原表为准：**HSCLK ≥ 表中速率即可**
> （占用率 ≤100%，含帧尾校验开销）；驱动 `check_hsdc_rate()` 已对齐该口径。

> 选型结论：7 通道全开 + 256 点时必须用 4.096MHz；512 点只能砍通道数。帧尾加校验还要再多留 32bit/帧 的余量。

### 2.10 MCU 侧（SPI 从机）接收要点

1. MCU 硬件 SPI 配 **从机模式、只收**（MOSI 不接），CPOL/CPHA 与 HDSC_CTL 一致（默认 CPOL=0/CPHA=1），用示波器实测一次采样边沿最稳妥。
2. 波特率按 2.9 节选；MCU SPI 从机最高时钟要 ≥ HSCLK（常见 MCU 从机 4MHz 以上没问题，注意查数据手册上限）。
3. 用 **INT（EMMIE2 半块输出中断）** 或芯片 BUSY 状态感知"半块发送开始"，再启动 DMA 连续接收半个缓存的数据量；HSCSN 拉高即为帧结束。
4. 接收后做两件事：按 2.4 表还原字节/位序；用帧尾 CHKSUM/CRC16（或回读 `HSDC_CRC` 寄存器）校验。
5. 24bit 采样值为有符号原始 ADC 码，按通道映射表分拣；注意 BYTE_INV=1 时字节顺序是低字节在前。
6. 错误处理：`EMUIF2.HSDC_ERR_IF` 置位时 HDSC_CTL.EN 自动清零，需重新走配置流程。

### 2.11 4V+3I（7 通道）推荐配置（2026-10 驱动审核修订版）

用户硬件：UA/UB/UC 三路电压 + 第 4 路电压接 IN 差分输入（INP/INN，管脚 18/19）+ IA/IB/IC 三路电流，共 7 通道，8K 采样。经手册逐项复核（p89-92 / p112 / p125-126 / p146-147 / p156-157）：

| 步骤 | 寄存器(地址,字长) | 寄存器值 → 线上字节（大端） | 说明 |
|---|---|---|---|
| 0 | — | 上电/复位等待 ≥50ms，读 DeviceID(0x18F,3B)=83 02 00 | 自检 |
| 1 | WREN(0x180,1B) | `0xE5` | 解锁 |
| 2 | WREN2(0x17F,4B) | `0x0000E5AA` → `00 00 E5 AA` | 解锁+扩位使能 |
| 2a | **WMSW(0x181,1B) = `0xA2`** | 切换到 EMM 计量模式 | 复位后默认测试模式，不切则计量/波形 DMA 可能不跑（p111；官方程序上电及每次整片复位后必写；必要性建议上板验证） |
| 3 | SYSCFG(0x178,4B) | 读改写 `\|= 0xEA001000` | bit12=HSDC_EN 有手册依据(p110)；0xEA000000 为厂商魔数（含保留位，量产代码背书） |
| 4 | SOFTRST(0x182,1B) | `0xE1` → `0x4C` | 复位 MMU 波形 DMA 与 HSDC |
| 5 | WSAVECON(0x163,1B) | **`0x82`** | BUFCFG[3:0]=0010 → **7 通道交叉（BUFCFG=10010）** |
| 6 | DMA_WAVECON(0x193,4B) | `0x00000001` | DS_CFG=01=**固定 8K**（勿用厂商 0x04——那是同步 256 点/周波≈12.8K） |
| 6a | IN_WaveEN(0x194,2B) | 保持复位 `0x0000`（实测 IN 无数据再写 `0x0001` 复测） | 7 通道模式 IN/IA 独立流转 |
| 6b | DMA_WAVECON2(0x1D1,4B) | 保持复位 `0x0003F800` | 勿抄厂商 0x0700（含 AGC，会改变原始波形幅值） |
| 7 | DMA_WAVECON3(0x1E5,4B) | **`0x00000402`** → 启动 `0x00000403` | bit10=交叉 + bit1=BUFCFG[4] + bit0=启动 |
| 8 | HDSC_CTL(0x1C9,4B) | **`0x0000040D`**（2.048MHz 用 `0x0000041D`） | 先写参数(EN=0)再置 EN=1 |
| 9 | EMMIE2(0x16B,4B) | 读改写 `\|= 0x00001800`（可先写 EMMIF2=0x1800 清残留标志） | 半块输出+错误中断，INT1 |
| 10 | WREN / WREN2 | `0xDC` / `0x0000DC55` | 恢复写保护 |

- **每采样点 7 个 24bit 的固定顺序（BUFCFG=10010，p147）**：`UA, UB, UC, IA, IB, IC, IN`。
- **帧 payload = 64 点 × 7 通道 × 3B = 1344B**，SUM32 帧尾 +4B → 1348B/帧；8K 下每 8ms 一帧（125 帧/s）。
- 带宽核算：纯数据 1.344Mbps，含帧尾/帧间隙 ≈1.349Mbps → **HSCLK=2.048MHz 即够**（占用 65.9%，帧时长 5.27ms < 8ms）；4.096MHz 占用 32.9%，余量最大（驱动默认）；1.024MHz 及以下帧发不完会触发 HSDC_ERR_IF 并自动清 EN，**不可用**。
- 校验字段字节序：手册时序图仅展示 BYTE_INV=0 场景，BYTE_INV=1 时校验字段字节序未明确——驱动默认 AUTO（两种序任一匹配），现场读 HSDC_CRC(0x1CA) 与本地结果比对定序后，把 `cs_order` 锁定为 BE/LE。

**上板必测清单（两轮独立审核均无法从手册闭环的点）：**
1. **WMSW 必要性**：不写 0xA2 与写 0xA2 两种情况下验证 7 通道数据是否出现；
2. **BYTE_INV=1 帧尾校验字节序**：读 HSDC_CRC(0x1CA) 与本地 SUM32 比对定序，锁定 `cs_order`；
3. **DMA_WAVECON2 复位值 0x3F800 的 AGC 位**：若默认开启会调制波形幅值，读回并按需清零，复测幅值线性度；
4. **GSxx_WAVE 增益寄存器复位值**：注入已知直流电平比对 ADC 码值，确认增益=1（厂商 HSDC.c 有写这些寄存器的痕迹）；
5. **DMA_WAVECON3 bit11**（厂商写 0xC00 含此位）：读回对比，确认保留位无副作用；
6. **DeviceID 实际返回值**（0x830200 或 0x830201）。

## 3. 驱动开发 Checklist / 常见坑

- [ ] **R/W 位极性**：0=读、1=写（与多数器件相反，易错）。
- [ ] SCSN 必须外接上拉（内部悬空）；SCSN 拉高才结束帧并复位移位寄存器。
- [ ] 校验和是"和取反"不是 CRC：`CS = ~(ADDR+CMD+DATA)`；HSDC 的累加校验和则**不取反**。
- [ ] 写寄存器前必须两级写使能（WREN=0xE5 + WREN2=0x0000E5AA），写完 WRDIS=0xDC / WREN2=0x0000DC55 恢复保护。WREN2 的 0xAA/0x55 是**扩位命令位（bit[7:0]）**，不是"首字节密钥"。
- [ ] **7 通道（4V+3I）必须同时改两处**：WSAVECON[3:0]=0010 且 DMA_WAVECON3[1]=1（BUFCFG=10010）；只置 bit1 不改 WSAVECON（BUFCFG=10000）不是 7 通道，帧定界随之崩溃。
- [ ] 4 字节寄存器按"地址+长度"译码为独立寄存器（如 WREN2 0x17F~0x182 与 WREN/WMSW/SOFTRST 同址段、EMMIF2 0x16C~0x16F 与 EMMIE2 窗口相邻），MCU 侧不要用平铺内存模型去模拟它们之间的覆盖关系。
- [ ] 寄存器字长 1/2/3/4 字节不等，按手册"字长"列传参，多字节先高后低。
- [ ] t1（字节间）、t2（末字节到 SCSN 上升沿）≥ 0.5 SCLK 周期——低速 CPU 用 GPIO 模拟时尤其注意。
- [ ] Burst 读寄存器每个固定 32bit（不是寄存器实际字长）；波形 Burst 每个固定 24bit；越界补 0 且计入校验。
- [ ] HDSC_CTL 只能在 EN=0 时配置；出错 EN 自动清零，要重新初始化。
- [ ] 7 通道 256 点必须 4.096MHz；512 点 7 通道超出能力。
- [ ] 初始化可先读 `DeviceID`（Bank1 8FH）== 0x830200 确认 SPI 链路和校验和算法正确。
- [ ] RN8302B/RN7302 **没有** HSDC（HSDAO 等引脚 NC）；波形只能经 SPI Burst 读缓存块。
